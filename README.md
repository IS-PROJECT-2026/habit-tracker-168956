# Habit Tracker

A single-page habit tracker built with vanilla HTML, CSS, and JavaScript. Add habits, mark them done for the day, and track your streaks — all persisted locally in your browser via localStorage.

## Features

- Add and delete habits
- Mark a habit as done for the current day
- Automatic streak calculation based on consecutive completed days
- Data persists across sessions using localStorage
- Responsive layout for mobile and desktop
